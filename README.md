# AI Change Log

Static site: AI tools that shut down, changed price, changed limits, deprecated a model, or changed policy — each entry dated, sourced, and marked confirmed vs reported.

- `index.html` — the feed
- `change/*.html` — one page per change
- `feed.json` — JSON Feed 1.1
- `llms.txt` — machine-readable summary for AI assistants
- `sitemap.xml` / `robots.txt`

Generated by `scripts/build.mjs` in the source repo (`labs/ai-changes`). Do not edit files here by hand; edit `data/events.json` and rebuild.
