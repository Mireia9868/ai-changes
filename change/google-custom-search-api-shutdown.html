Google Custom Search JSON API is being shut down — migration options for site search and RAG

Short answer. Reports on October 30, 2026 say Google is retiring the Custom Search JSON API, the endpoint many products used for cheap programmatic web search. Teams using it for site search, RAG retrieval or content monitoring need a replacement. We have not yet confirmed the exact shutdown date on Google's own documentation.

Who this affects

For Developers

Products and agents that call the Custom Search JSON API directly, and anything built on a CSE ID.

What to do

  • Inventory every call to customsearch.googleapis.com and note query volume and billing.
  • Shortlist replacements by cost per 1k queries, result freshness, and whether the terms allow storing results.
  • Keep a fallback path: run both providers in parallel for a week before cutting over.

What to check

  • Cost per 1k queries after migration
  • Result freshness parity
